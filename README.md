# 隐私权政策 (Privacy Policy)

最后更新日期：2026年10月

**简洁式双语翻译助手**（以下简称“本扩展”）尊重并保护所有用户的个人隐私。本隐私政策旨在说明本扩展如何处理您的信息。

### 1. 我们收集哪些信息？
本扩展不会收集、上传或向开发者服务器传输您的任何个人身份信息或浏览历史。为了正常运行，本扩展会在您的本地浏览器中存储以下数据：
*   **配置信息**：您选择的翻译引擎、源语言、目标语言、界面显示模式等偏好设置。
*   **身份验证信息（API 凭证）**：如果您使用百度翻译或 AI 大模型（如 OpenAI、DeepSeek、Kimi 等），您需要在设置页手动输入您的 API Key 或 AppID。这些凭证属于“身份验证信息”。

### 2. 数据如何使用与传输？
*   您填写的所有配置信息和 API 凭证均使用 Chrome 官方提供的 `chrome.storage.sync` 接口保存在您的本地浏览器（及您登录的 Chrome 账号同步中）。
*   当您触发翻译时，本扩展会将当前网页上的**待翻译文本**以及您的 **API 凭证**，直接发送给您选定的第三方翻译服务商（如 Google、百度、OpenAI 等）。
*   **开发者不运营任何服务器，绝不收集、查看、存储或拦截您的任何数据。**

### 3. 第三方服务
由于本扩展依赖第三方翻译接口，当您使用相关服务时，您的文本和凭证将受该第三方服务商的隐私政策约束（例如 Google 隐私权政策、OpenAI 隐私权政策、百度翻译 API 使用条款等）。建议您查阅相关服务商的隐私条款。

### 4. 数据删除
您可以随时在 Chrome 浏览器中卸载本扩展，或清除扩展的存储数据（通过 Chrome 设置 -> 扩展程序 -> 本扩展 -> 清除数据），所有本地保存的配置和 API Key 将被永久删除。

### 5. 联系方式
如果您对本隐私政策有任何疑问，请通过 Chrome Web Store 开发者联系邮箱与我们沟通。
